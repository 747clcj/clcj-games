# نشر ألعاب CLCJ على Streamlit

الملفات (3 بس):
- `app.py`
- `requirements.txt`
- `clcj_games_offline.html`

## الخطوات
1. ادخل github.com بحسابك واعمل Repository جديد (اسمه مثلاً `clcj-games`).
2. ارفع الملفات التلاتة في أول مستوى للـ Repository (Add file > Upload files).
3. ادخل share.streamlit.io وسجّل دخول بحساب GitHub.
4. اضغط Create app واختار الـ Repository والـ Branch (`main`) والـ Main file path: `app.py`.
5. اضغط Deploy، وبعد دقيقة هتاخد رابط بشكل `xxx.streamlit.app`.

## ملحوظات
- البيانات (النقاط والبادجات والسجل) بتتحفظ جوه متصفح كل جهاز، ومفيش تزامن بين المحاضرين.
- من تبويب الملخص: نسخة احتياطية، واستيراد ملفات المحاضرين التانيين عشان تجمع البادجات.
- لو محدش فتح الرابط فترة، Streamlit ممكن ينيّم التطبيق، وأول فتحة بعدها بتاخد لحظة.
